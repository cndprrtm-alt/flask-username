Aplikasi Pengecekan Username dengan Flask



Deskripsi



Aplikasi web sederhana menggunakan Python Flask untuk mengecek dan memvalidasi username.



Fitur



\* Halaman Beranda

\* Halaman Tentang

\* Halaman Produk

\* Halaman Kontak

\* Pengecekan username melalui route dinamis

\* Validasi username

\* Detail produk menggunakan ID integer

\* Penggunaan url\_for dan redirect

\* Halaman error 404 khusus



Teknologi



\* Python

\* Flask

\* Git

\* GitHub



Cara Menjalankan



1\. Install Flask dengan perintah py -m pip install flask.

2\. Buka terminal pada folder project.

3\. Jalankan aplikasi dengan perintah py app.py.

4\. Buka browser dan akses http://127.0.0.1:5000.
